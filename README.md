C语言计算机程序：
一个用 C 语言实现的**交互式计算器**，支持基础四则运算和科学计算功能（乘方、平方根、阶乘）。代码模块化设计，可作为学习 C 语言函数、控制流和数学库的参考示例

**基础计算器**：支持加法 `+`、减法 `-`、乘法 `*`、除法 `/`（含除零错误检测）
**科学计算器**：
  - 乘方运算（`a^b`）
  - 平方根（`√x`，负数输入报错）
  - 阶乘（`n!`，仅非负整数）
**友好的菜单交互**，循环执行直到用户选择退出
**输入错误处理**（非数字、格式错误等）
**函数分离**，每个运算独立封装，便于维护和扩展

环境要求：
支持 C99 或更高版本的编译器（GCC、Clang、MSVC 等）
数学库（`libm`）—— 用于 `pow()` 和 `sqrt()`

编译命令（GCC / MinGW）：
```bash
gcc -o calculator main.c -lm
