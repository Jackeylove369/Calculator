# 多功能计算器（C 语言实现）

> 一个支持基本运算和科学计算的交互式命令行计算器，适合学习 C 语言函数模块化编程。

## 功能概览

| 模式 | 功能 | 说明 |
| :--- | :--- | :--- |
| **基本计算器** | 加法、减法、乘法、除法 | 输入格式：`数字1 运算符 数字2`（如 `3.5 + 2.1`） |
| **科学计算器** | 幂运算 (`a^b`) | 计算任意实数的幂 |
| | 平方根 (`√x`) | 计算非负数的平方根 |
| | 阶乘 (`n!`) | 计算非负整数的阶乘（递归实现） |
| **退出程序** | 安全退出 | 释放资源，返回系统 |

## 代码结构

| 模块 | 函数 | 作用 |
| :--- | :--- | :--- |
| 主控制 | `main()` | 显示主菜单，循环接收用户选择，调用对应计算模式 |
| 基本运算 | `add`, `subtract`, `multiply`, `divide` | 四则运算函数（返回 double 结果） |
| 基本界面 | `simpleCalculator()` | 接收表达式，调用运算函数并输出结果 |
| 科学计算 | `power`, `squareRoot`, `factorial` | 分别调用 `math.h` 的 `pow`/`sqrt`，阶乘用递归实现 |
| 科学界面 | `scientificCalculator()` | 显示子菜单，引导用户选择科学计算类型 |
| 辅助 | 错误处理 | 检查除零、负数开方、负阶乘、输入格式错误等 |

## 编译与运行

- **编译环境**：任何支持 C99 或更高标准的编译器（GCC、Clang、MSVC）。
- **编译命令**（以 GCC 为例）：
  ```bash
  gcc -o calculator calculator.c -lm
